# Zenvo Security and Data Privacy

Zenvo protects clinic and patient communication data with strict healthcare-grade safeguards.

## Encryption & Storage
- All data in transit is encrypted using TLS 1.3, and all data at rest is encrypted using AES-256.
- Patient data is hosted in secure Indian cloud data centers (Mumbai region) to support local data residency needs.

## Privacy & Access Controls
- Role-based access control (RBAC) ensures front-desk staff only see scheduling details they need.
- Zenvo only stores minimal appointment metadata (patient name, phone number, slot time, doctor name) and never stores clinical diagnoses or medical records.
- We never sell, rent, or share patient phone numbers with third parties.

## Compliance & Reliability
- Automated daily encrypted backups with 30-day retention.
- Audit logs track all login and appointment export activity on Pro and Enterprise plans.
- Opt-out ("STOP") requests from patients are respected immediately across all channels.
